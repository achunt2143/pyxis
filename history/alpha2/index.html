ALPHA 2

The first Pyxis that boots to a desktop. The shell starts on its own, and apps open as real windows that Evo composites.

What it did

A desktop of its own

Alpha 2 turned the pieces of alpha 1 into something you could sit in front of, and laid the groundwork for installing apps.

Apps in their own windows

Each app opens in a window of its own, drawn and framed by Evo, instead of inside the shell's page. The shell stays on the bottom layer, so apps can't vanish beneath it.

  • The title bar carries the app's name and three controls: a triangle, a square and a circle.
  • Firefox's toolbar still showed in app windows. Making apps chromeless every time took until alpha 4.
  • New windows open partly off screen and have to be dragged into view.

Vela is the browser

Clicking Browser opens the web straight away, in Pyxis's own build of Gecko.

A real shell, and a missing package manager

The Terminal is real. But ask it for opkg, the package manager the new App Installer needs, and it isn't there.

  • Nova, the app host, now knows every app, composes its launch and can install or remove apps.
  • Vroom became the Pyxis SDK and PDK, building .ipk packages for web and native apps.
  • Without opkg in the image, none of it could install anything yet. Alpha 3 fixed that.

Status that wasn't true

Quick settings looked complete. It wasn't: the battery read 50% on a machine with no battery, the network read not connected on a working connection, and every switch read Off.

Eight apps

The App Installer joined Terminal, Browser, Files, Notes, Contacts, Tasks and Settings. Settings are now saved, so a choice survives a restart.

Not yet

What it couldn't do

Written down at release, so the next alpha knew where to start.

  • Restoring a maximized window closed the app.
  • Clicking a minimized app's dock icon didn't bring it back.
  • Files showed placeholder folders, not what was on disk.
  • Windows couldn't be resized.
  • The status bar and quick settings showed made-up values.
  • The App Installer couldn't install anything: there was no package manager in the image.
  • Any program on the bus could still call any service.
What came next

Alpha 3: nothing lies to the user

  • Every made-up value was made real, or replaced by an honest “not available”.
  • opkg shipped in the image, and the services stopped dying at boot.
