ALPHA 4

Alpha 3 made Pyxis stop lying. Alpha 4 makes it useful: an app someone else built installs, shows up on the desktop, and runs.

About these pictures. No alpha 4 image was kept, so one was rebuilt for this page from the alpha 4 sources: the same Rust, shell and apps, its own Gecko patch series compiled from scratch, and the kernel it shipped with.

What it did

All my apps working

Alpha 4's test was simple to say: package an app with the Pyxis SDK, install it, and see it on the desktop with no change to Pyxis.

The app list is live

The launcher, drawer, search and dock now read Nova's registry of apps, instead of a list written into the shell. The new Applications panel shows every app as a coloured waterdrop.

  • Filter by All, PIM or System, or search by name.
  • Move through it with the arrow keys and press Enter to launch.
  • An app the shell has never heard of still appears, drawn with its own icon or a plain glyph.

Install a package

The App Installer finds packages waiting in the incoming folder, shows what each one is and asks for, then runs opkg and refreshes the registry.

It shows up, and it runs

The moment the install finishes, Hello Pyxis is in the drawer. Click it and it opens in its own window, at its own address, with the bridge to the system in place.

  • It runs at pyxis://com.pyxis.hello, a secure context of its own.
  • The page checks its own surroundings and prints them: origin, bridge, and the system calls it can reach.
  • Removing the package takes it off the desktop again, with no restart.

Windows that behave

The window bugs that had followed Pyxis since alpha 2 are closed. Restore a maximized window and the app keeps running.

  • Clicking a minimized app in the dock brings it back.
  • The close button really asks the app to close, and a closed window is really gone.
  • An app opened again no longer comes back as a Firefox window with a toolbar.
  • Firefox's sandbox notice no longer stacks a bar in every app window.

Eight apps, all launching

Terminal, Browser, Files, Notes, Contacts, Tasks, Settings and the App Installer all launch, focus, minimize, restore and close. Running all eight at once needs 4 GB, so the reference VM grew to match.

Not yet

What it couldn't do

Written down at release, so the next alpha knew where to start.

  • Windows couldn't be resized by dragging their edges or corners.
  • Shift's process layer was still simulated under real bookkeeping.
  • The kernel had no user namespaces, so the web engine's content sandbox was weaker than intended.
  • There was no install-time permission prompt, and no way to see or revoke what an app was granted.
  • There was no sound.
  • The status bar still drew its own white bar, and the shell sat beneath every app, so its panels could open behind windows.
What came next

Alpha 5: a desktop that behaves like light

  • Pyxis got its own look: the Daylight wallpaper, frosted waterdrop windows and Lumen motion.
  • Every app got its own user and sandbox, sound arrived, and one dialog asks for your password.
