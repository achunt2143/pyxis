Alpha 3 · September 2026

ALPHA 3

Alpha 3's rule was nothing lies to the user. Everything alpha 2 faked is either real now, or honest about what it can't do.

What it didNot yetWhat came nextRelease notes
What it did

Honest, and reliable

Few new features, on purpose. Alpha 3 went through every number and switch on screen and made each one tell the truth.

Status you can believe

The network indicator reads the kernel, so a wired connection shows as connected, with its interface name. A machine with no battery says so.

  • Switches that did nothing were removed.
  • Dark Mode and “Show percentage in top bar” really change things now.
  • The clock ticks, on the minute.

A package manager, at last

opkg ships in the image for the first time, built from a pinned, checksum-verified source, because Debian packages none.

  • The App Installer finally has something to install with.
  • Terminal and Files open full screen, with Evo's title bar and no Firefox toolbar.

Files shows your files

Folders list what is really on disk. One unreadable entry no longer blanks the whole listing, and images preview inline.

The App Installer

The installer is in the app list, with a four-step flow: choose a package, review it, install, done.

  • It looks for .ipk packages in /var/lib/pyxis/incoming, /tmp and mounted drives.
  • Installed apps didn't show up on the desktop yet: the shell's app list was still fixed. Alpha 4 fixed that.

Desktop search

Type in the top bar and matching apps appear. Press Enter to open one.

Not yet

What it couldn't do

Written down at release, so the next alpha knew where to start.

  • Installed apps didn't appear in the launcher, dock or search.
  • Clicking a minimized app's dock icon didn't bring it back.
  • Restoring a maximized window down closed the app.
  • Windows couldn't be resized.
  • Some apps opened as a regular Firefox window, toolbar and all.
  • There was no sound.
What came next

Alpha 4: all my apps working

  • A package built with the Pyxis SDK installs, appears on the desktop, launches and uninstalls, with no code change.
  • The fixed app list was replaced by Nova's live registry.
