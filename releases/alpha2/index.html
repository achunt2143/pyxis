Pyxis alpha 2

Released 27 July 2026.

Alpha 2 is the first Pyxis that boots to a desktop. The Bloom shell starts on its own, apps open as real windows that Evo composites, and the browser is Vela. Underneath, the pieces for installing apps arrived: Nova, the app host, and Vroom, the toolkit that builds Pyxis app packages. It shipped after a full on-device test pass, with the bugs that pass found written down and carried into alpha 3.

Highlights

  • A desktop at boot. The machine starts into the Bloom shell: a top bar with search, a dock and a wallpaper.
  • Apps are real windows. Each app opens in its own window that Evo draws and frames, not inside the shell's page.
  • The shell stays behind your apps. Evo keeps the desktop on the bottom layer, so app windows can't disappear beneath it.
  • Vela is the browser. Clicking Browser opens the web straight away in Pyxis's own engine.
  • Settings are saved. Settings survive a restart.
  • Eight apps. The new App Installer joins Terminal, Browser, Files, Notes, Contacts, Tasks and Settings.
  • The groundwork for installing apps. Nova knows every app, launches it and can install or remove it; Vroom builds .ipk packages for web and native apps.

What changed since alpha 1

  • The dock launches apps, and shows a small light under the ones that are running.
  • Windows have a title bar drawn by Evo, with the app's name and minimize, maximize and close buttons.
  • Minimize works, and the dock keeps a minimized app's icon.
  • Opening an app gives one clean window. The first launch is no longer a plain browser window.
  • The quick settings panel opens from the gear in the top bar.

Under the hood

  • Nova, the app host, is built: it reads each app's manifest, gives every app its own pyxis:// origin, composes its launch, installs and removes apps with an integrity check, and allows one copy of each app at a time.
  • The installer service handles .ipk packages through opkg.
  • Vroom became the Pyxis SDK and PDK: pyxis, pyxis-sdk and pyxis-pdk commands that build, package and install apps. (Its old life as a performance monitor with made-up numbers was deleted.)
  • Settings are stored in one file in /var/lib/pyxis, whoever is logged in.
  • The changes Pyxis makes to Gecko now live in the repository as a patch series, with a script to regenerate and check it.

Known issues

  • Restoring a maximized window closes the app.
  • Clicking a minimized app's dock icon does not bring it back.
  • Files shows a fixed set of folders instead of what is really on disk.
  • Windows can't be resized.
  • Apps still show Firefox's toolbar for the first seconds after they open, and new windows open partly off screen.
  • The top bar and quick settings show made-up values: 50% battery, no network, and every switch reads Off.
  • The App Installer can't install anything: the image has no package manager yet.
  • Any program connected to the bus can still call any service.

Trying it

Pyxis alpha 2 boots as a disk image in QEMU. The reference VM has 2 GB of memory and 4 CPUs.
